# Fire It Up

**Fire It Up** — Android-приложение с визуальными игровыми заданиями на поиск совпадающего элемента. Игроку одновременно показываются две карточки со словами; необходимо найти единственное слово, присутствующее на обеих карточках.

Проект разрабатывается как практический пример для выпускной квалификационной работы на тему **«Разработка алгоритма формирования визуальных игровых заданий с управляемым уровнем сложности на реальном практическом примере»**. Текущая версия приложения позволяет отрабатывать базовый игровой цикл и служит основой для последующего исследования сложности заданий и разработки алгоритма их управляемого формирования.

## Текущее состояние

На данный момент в приложении реализованы:

- стартовый экран и переход к выбору игрового режима;
- формирование пары карточек по четыре слова с одним общим словом;
- случайный выбор общего слова, остальных слов и порядка элементов на карточках;
- обработка выбора слова на карточке игрока и генерация новой пары карточек после правильного ответа;
- три игровых режима:
  - **«Бесконечный режим»** — на поиск совпадения отводится ограниченное время; после правильных ответов отсчёт запускается заново, а доступное время постепенно сокращается с 10 до 4 секунд; ошибка или истечение времени завершает игру;
  - **«Игра на время»** — за 60 секунд требуется набрать как можно больше очков; ошибка уменьшает оставшееся время на одну секунду;
  - **«Забег»** — требуется правильно пройти 25 карточек за минимальное время; ошибка завершает попытку;
- экраны завершения игры и возможность начать выбранный режим заново;
- сохранение лучших результатов по очкам для бесконечного режима и игры на время в локальном хранилище Android (`SharedPreferences`);
- светлая и тёмная цветовые схемы, включая динамические цвета на Android 12 и новее.

Интерфейс содержит элементы для локальной игры вдвоём, правил и настроек, однако отдельная логика этих разделов в текущем коде отсутствует. Кнопка онлайн-мультиплеера отключена.

## Технологии

- Kotlin 2.0.21;
- Android SDK: `minSdk 24`, `targetSdk 36`, `compileSdk 36`;
- Jetpack Compose и Material 3 для пользовательского интерфейса;
- Navigation Compose для навигации между экранами;
- AndroidX Lifecycle, `ViewModel` и Kotlin Coroutines для управления состоянием и таймерами;
- `SharedPreferences` для локального хранения результатов;
- Gradle Kotlin DSL и Android Gradle Plugin 8.13.2;
- JUnit, AndroidX Test и Espresso представлены в тестовых зависимостях проекта.

## Структура проекта

Проект состоит из одного Android-модуля `app`. Основной код расположен в `app/src/main/java/com/vasya/yourdobble`:

- `data/repository` — получение набора слов из ресурсов и работа с локально сохранёнными результатами;
- `domain` — формирование пары игровых карточек;
- `model` — модель данных карточек;
- `navigation` — маршруты и связывание экранов с моделями представления;
- `viewmodel` — состояние и правила трёх игровых режимов;
- `viewmodel/factory` — создание моделей представления с необходимыми репозиториями;
- `ui/components` — переиспользуемые элементы карточек;
- `ui/screen` — стартовый экран, выбор режима и игровые экраны;
- `ui/theme` — цветовые схемы и типографика приложения.

Строковые, графические и тематические ресурсы находятся в `app/src/main/res`.

## Запуск проекта

Для сборки необходимы Android Studio с поддержкой используемых версий Android Gradle Plugin и Kotlin, JDK 11 и установленный Android SDK 36.

1. Клонируйте репозиторий и откройте его корневую папку в Android Studio.
2. Дождитесь синхронизации Gradle.
3. Выберите эмулятор или Android-устройство с API 24 или новее.
4. Запустите конфигурацию модуля `app`.

Отладочную сборку также можно создать из корня проекта:

```powershell
.\gradlew.bat assembleDebug
```

В Linux или macOS:

```bash
./gradlew assembleDebug
```

## Развитие в рамках ВКР

Перечисленные ниже направления являются **планами дальнейшей разработки и исследования**, а не описанием уже реализованной функциональности:

- формализация характеристик визуальных игровых заданий;
- сбор данных о прохождении игровых заданий;
- исследование факторов, влияющих на сложность;
- разработка модели оценки сложности;
- разработка алгоритма формирования заданий с управляемым уровнем сложности;
- экспериментальная проверка разработанного алгоритма.

Ожидается, что приложение станет экспериментальной средой, в которой разработанный алгоритм можно будет проверять на реальных игровых сессиях и сопоставлять заданный уровень сложности с результатами прохождения.
